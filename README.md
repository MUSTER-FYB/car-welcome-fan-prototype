# 浮光跃金 · 车门迎宾投影交互原型 (Car Door Welcome Fan Projection)

一款基于 **WebGL 实时着色器 + 三维地平面车门圆弧单应映射** 的汽车开门迎宾投影交互原型，配套 **Adobe After Effects 一键建工程脚本（`build_ae_project.jsx`）**。

## 在线演示 (GitHub Pages)
- **公网预览**：https://muster-fyb.github.io/car-welcome-fan-prototype/

## 核心特性
- **车门转轴机械联动**：以主驾车门铰链转轴 `O` 为极坐标圆心，扇面两条直线边分别贴合**车身门槛**与**开启中的车门底边**，圆润外弧线精准贴合车门扫过的真实三维圆弧轨迹。
- **分层材质与透明控制**：
  - 黑色与镂空区：100% 全透明（完整透出深灰反光地坪与车位线）
  - 云雾白扇面：半透明磨砂轻纱质感（默认 52%，可实时调节）
  - 流金脉络：100% 不透明实色香槟金 + 实时「浮光跃金」液态金波、斜向扫光与星芒微闪
- **三段式迎宾时序**：
  1. 开门同步展开（默认 `2.0s`）
  2. 全开浮光跃金驻留（默认 `1.0s`）
  3. 优雅光尘羽化消散（默认 `1.8s`）
- **交互与演示工具**：
  - `Space`：一键触发完整迎宾动画
  - `H`：进入 / 退出无 UI 纯净全屏演示模式
  - 支持手动拖动车门角度（`0°–68°`）、鼠标拖拽校准地面车门弧线 4 锚点、以及浏览器一键录制导出 1080p `.webm` 演示视频

## 本地运行
双击 `preview.bat`，或运行：
```bash
python serve.py
```
然后访问 `http://127.0.0.1:8765/index.html`。

## Adobe After Effects 一键搭建工程
打开 After Effects → **文件 (File) → 脚本 (Scripts) → 运行脚本文件 (Run Script File)** → 选择 `build_ae_project.jsx`，即可自动导入 `assets/` 中的分层透明素材并搭建好完整合成与关键帧。
